# 🌟 DeepSeek Recovery Kit

> Recover, search, and export your DeepSeek chat history — with code extraction, callback detection, and memory bank preservation.

[![MIT License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Python 3.12+](https://img.shields.io/badge/Python-3.12+-green.svg)](https://python.org)

## 🚀 What Does It Do?

Have you ever lost a long DeepSeek conversation due to context limits? This tool **recovers everything** from your exported JSON files:

- ✅ **All messages** — Searchable, filterable by date
- ✅ **Code snippets** — Extract C#, Python, SQL, and more
- ✅ **Callbacks** — Find all your bot button handlers
- ✅ **Decisions** — Your "memory bank" of agreed plans
- ✅ **Beautiful HTML** — Easy to search with NEXT button

## 📦 Features

| Feature | Description |
|---------|-------------|
| 🖥️ **GUI Mode** | Easy date picker and file browser |
| ⌨️ **CLI Mode** | For automation and scripting |
| 📅 **Date Filter** | Extract only what you need |
| 🔍 **Search with Next** | Navigate through matches |
| 💾 **Lightweight** | 500KB HTML (not 50MB!) |
| 🚀 **Fast** | Processes 45MB JSON in 2 seconds |
